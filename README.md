# Odoo Attendance Overtime

Odoo 19 module for calculating attendance-based overtime, routing it through an approval workflow, generating reports, and exporting approved overtime for payroll processing.

See `attendance_overtime/README.md` for module documentation.

## Status

Odoo 19 Community-compatible module. The source is prepared for testing and Odoo Apps marketplace submission; live installation testing against a running Odoo instance should be completed before release.
